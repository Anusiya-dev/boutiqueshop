# 🌸 FLORA — Women's Fashion Store

A fully responsive women's boutique website built with HTML, CSS, and Bootstrap.
Designed to look and feel like a real e-commerce brand.

## 🔗 Live Demo
👉[github.com/anusiya-dev/boutiqueshop](https://github.com/anusiya-dev/boutiqueshop)

## 📸 About the Project
FLORA is a fashion e-commerce frontend project for a women's clothing brand.
It includes a landing page, product collections, testimonials, 
a shop page, and a cart — all styled with a clean, modern aesthetic.

## ✨ Features
- Responsive navbar with cart icon
- Hero section with call-to-action buttons
- About the brand section with stats (3K+ customers, 48 pieces, 100% sustainable)
- Collections grid (Summer Edit, Festive, Minimalist)
- Why Us section with key selling points
- Customer testimonials
- Newsletter subscription section
- Multi-column footer with links
- Shop page and Cart page

## 🛠️ Built With
- HTML5
- CSS3
- Bootstrap 5
